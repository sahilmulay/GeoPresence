# Voice Assistant Audio Files

To make the Voice Assistant work perfectly, please use Sarvam AI (or any other text-to-speech service) to generate the following MP3 files and place them in this folder. Make sure the file names match exactly.

### Marathi Files (`_mr.mp3`)
1. **File Name:** `checkin_mr.mp3`
   **Text:** उपस्थिती नोंदवण्यासाठी 'चेक इन' बटणावर दाबा.
   *(Upasthiti nondavanyasathi 'check-in' button-var daba.)*

2. **File Name:** `startwork_mr.mp3`
   **Text:** तुमची कामे प्रलंबित आहेत. काम सुरू करण्यासाठी 'काम सुरू करा' वर दाबा.
   *(Tumchi kame pralambit aahet. Kam suru karnyasaathi 'start work' var daba.)*

3. **File Name:** `done_mr.mp3`
   **Text:** आजसाठी सर्व कामे पूर्ण झाली आहेत.
   *(Aajsaathi sarv kame purn jhali aahet.)*

### English Files (`_en.mp3`)
1. **File Name:** `checkin_en.mp3`
   **Text:** Please press the Check In button to mark your attendance.

2. **File Name:** `startwork_en.mp3`
   **Text:** You have pending tasks. Press Start Work to begin.

3. **File Name:** `done_en.mp3`
   **Text:** All tasks for today are completed.

### Important:
The app will automatically look for these exact file names in `public/audio/`. If a file is missing, the app will show an alert telling the user to add it.
